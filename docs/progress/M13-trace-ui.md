d) API contract (docs/progress/M12-api.md "Contract as built", src/ragdocs/schemas.py, pipelines/base.py):
- `trace` SSE event: TraceEvent {type, node, message, data, t_ms}. type is one of node_start, node_end, decision, retrieval, answer, error; only the first four are sent as `trace` events. `answer` SSE event: PipelineResult {question, pipeline, answer, contexts, trace, llm_calls, latency_ms, used_web, diagnostics (only when non-empty)}. `error` SSE event: {"error": string}. Keep-alive is the comment frame ": ping".
- Answer {text, citations [{chunk_id, url}], abstained}.
- Citation to context: contexts is the list of RetrievedChunk {chunk, score, rank, retriever}; chunk has chunk_id, doc_path, url, title, heading_path, anchor, text, embed_text, n_tokens, has_code, source_commit. A citation matches contexts[i].chunk.chunk_id (answer.py _extract_chunk builds Citation from the chunk). Inline [n] markers in the text (when present, D20) are 1-based positions in contexts: n = index + 1 (answer.py: chunks[c_idx - 1]). The UI needs chunk.url, title, heading_path, rank and score.
- Non-200 /api/ask (JSON, `{"error": ...}`): 413 "Request body too large."; 422 "Send JSON with a \"question\" string."; 422 "Unknown pipeline. Choose baseline, corrective or self_rag."; 422 "The question must be between 3 and 500 characters."; 422 "The question contains unsupported control characters."; 429 "Rate limit reached. Try again later." plus `retry_after_s` and header `Retry-After: N`; 503 "The demo's daily budget is used up. It resets at 00:00 UTC."; 503 "The service is temporarily unavailable."; 500 "Internal error.". Success is 200 text/event-stream; later failures are an SSE `error` event with HTTP 200.
- GET /api/pipelines returns {"pipelines": [{name, label, description}]} (app.py line 166; the M12 file does not say the wrapper object, found in the source).
e) From per_question.jsonl, item q001 of each run:
- baseline retrieval event: data {"mode": "hybrid", "chunks": [{rank, title, heading_path, url, score}]}. No chunk_id and no query. It does list rank, title, heading_path and score, so the UI can show it as is.
- corrective and self_rag retrieval event: data {"mode", "query", "chunks": [{chunk_id, url, rank, score, title, heading_path}]}.
- decision events: corrective grade_documents: data {"grades": [{index, chunk_id, relevant, reason}], ...} (message "4 of 5 chunks relevant"); self_rag decide_retrieval: data {"needs_docs": true, "reason": "...", "outcome": "ok"}. Every decision has data.outcome in ok, retry, stop, info (D25).
f) CSP string (M14): `default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; connect-src 'self'; frame-ancestors 'none'; base-uri 'self'`. MDN (https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/style-src): inline <style> blocks and style="" attributes are blocked, as is setAttribute("style") and style.cssText; "styles properties that are set directly on the element's style property will not be blocked" (element.style.x = ...), which is what React uses. The MDN example policy uses a host source, not 'self'; a policy without 'unsafe-inline', a nonce or a hash blocks the same inline styles.
